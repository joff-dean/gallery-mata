# Gallery Mata

기존 로컬 앨범을 정답 예시로 사용해 스크린샷, 다운로드 이미지, 화면 녹화를 기기 안에서 1차 분류하는 Android 앱입니다.

## 현재 APK의 기능

- Android `MediaStore`에서 로컬 이미지·영상 앨범 검색
- 분류 기준 앨범과 미분류 소스 폴더 직접 선택
- 한국어/영문 OCR, 색상·레이아웃 특징, 지각 해시를 결합한 오프라인 분류
- 화면 녹화의 시작·중간·끝 대표 프레임 분석
- 높은 확신 항목만 기본 선택하고 나머지는 사용자 검토
- 결과별 대상 앨범 수정
- Android 시스템 쓰기 승인 후 실제 폴더 이동
- 최근 이동 묶음 되돌리기
- 특징 캐시를 이용한 두 번째 분석 가속

앱에는 인터넷 권한이 없습니다. 원본, OCR 결과, 특징 벡터는 외부 서버로 전송되지 않습니다.

## 권장 테스트 순서

1. 휴대폰 설정에서 중요한 사진을 별도로 백업합니다.
2. 기존 분류 앨범마다 가능하면 10개 이상의 예시를 준비합니다.
3. 앱을 설치하고 사진·영상 접근을 허용합니다.
4. `앨범 검색` → `기준 앨범` → `미분류 위치` 순으로 선택합니다.
5. 처음에는 20~50개 정도가 든 소스 폴더로 테스트합니다.
6. `분석 시작` 후 체크 상태와 대상 앨범을 검토합니다.
7. `선택 이동`을 누르고 Android 시스템 확인 화면을 승인합니다.
8. 문제가 있으면 `최근 이동 취소`를 사용합니다.

Android 14 이상에서 “선택한 사진만” 권한을 주면 그 사진들만 검색됩니다. 전체 갤러리 정리를 시험하려면 전체 사진·영상 접근을 선택해야 합니다.

## 빌드

JDK 17과 Android SDK 36이 필요합니다.

```bash
./gradlew assembleDebug
```

산출물은 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## 알려진 범위

- 로컬 폴더 기반 앨범만 이동할 수 있습니다.
- Google Photos 클라우드 전용 앨범, 보안 폴더, OEM 전용 가상 앨범은 대상이 아닙니다.
- 첫 버전은 개인별 대규모 신경망 재학습 대신 예시 유사도 방식입니다. 실제 수정 데이터를 축적한 뒤 임계값과 모델을 고도화할 수 있습니다.
- Android 10에서는 파일별 시스템 승인 화면이 표시될 수 있습니다. Android 11 이상에서는 묶음 승인을 사용합니다.

## 개인정보 원칙

- 네트워크 권한 없음
- 번들된 ML Kit 한국어 OCR 모델 사용
- 분석 데이터는 앱 전용 SQLite 데이터베이스에 저장
- 앱 삭제 시 분석 캐시와 이동 기록 삭제
